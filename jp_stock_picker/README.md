# 日本株 銘柄選定システム (jp_stock_picker)

日経225採用銘柄を対象に、**短期(~1週間) / 中期(数週間~数ヶ月) / 長期(1年以上)** の
3つの投資期間それぞれに適した銘柄をスクリーニングする。全銘柄「1株10,000円以下」に限定。

## セットアップ

```bash
pip install -r jp_stock_picker/requirements.txt
```

## 実行方法

`C:\Users\hyuga\Python\main` ディレクトリから:

```bash
python -m jp_stock_picker.main --horizon all      # 短期・中期・長期すべて
python -m jp_stock_picker.main --horizon short --top 10
python -m jp_stock_picker.main --refresh-cache    # キャッシュを無視して再取得
```

結果はコンソールに表示され、`jp_stock_picker/output/` 配下にCSVとMarkdownサマリーが保存される。

## 仕組み

| ファイル | 役割 |
|---|---|
| `universe.py` / `_nikkei225_data.py` | 日経225の銘柄マスタ(コード・社名・業種) |
| `data_fetcher.py` | yfinanceから株価・ファンダメンタルズを取得(ディスクキャッシュ付き) |
| `indicators.py` | RSI・MACD・移動平均・一目均衡表などのテクニカル指標 |
| `scoring.py` | 各指標を0-100のパーセンタイルスコアに変換し、重み付き合成する共通処理 |
| `screeners/short_term.py` | 短期スクリーナー: モメンタム・トレンド・出来高確認・ブレイクアウト位置 |
| `screeners/mid_term.py` | 中期スクリーナー: 対日経平均の相対力・トレンドテンプレート・ROE |
| `screeners/long_term.py` | 長期スクリーナー: PER/PBR(バリュー)・ROE(クオリティ)・配当・成長性 |
| `report.py` | 結果の整形出力(コンソール表 + CSV/Markdown) |
| `main.py` | CLIエントリポイント |

## スクリーニングの考え方

- **短期(~1週間)**: 短期は業績よりも価格・出来高の需給が支配的。ゴールデンクロス、MACD、
  RSI、25日移動平均乖離率、出来高急増、52週高値圏かどうかを見る。
- **中期(数週間~数ヶ月)**: 対TOPIX/日経平均の相対力(RS)とトレンドテンプレート(株価が
  上昇中の75日線・200日線の上にあるか)を軸に、ROEによる「クオリティ」の裏付けを加える。
  本来この期間は機関投資家・海外投資家フローや業績リビジョン指数が重要な材料だが、これらは
  yfinanceからは取得できないため今回は反映していない(将来の拡張候補)。
- **長期(1年以上)**: バリュー(PER・PBR)・クオリティ(ROE、TSEの資本コスト基準8%を参照)・
  配当(利回り・配当性向)・成長性(増収増益)を総合評価。東証のPBR改革(低PBR×低ROEは
  自社株買い・増配・非公開化などの再評価候補)に該当する銘柄は `reform_candidate` 列で
  フラグを立てる。

## 既知の制約(今後のフィードバックで改善予定)

- 銘柄ユニバースは日経225のみ(TOPIX全銘柄などへの拡張は今後検討)
- 信用取引残高、外国人投資家売買動向、アナリストのリビジョン指数など、日本市場特有の
  中期シグナルは無料データソースでは取得できないため未反映
- ファンダメンタルズはyfinanceの`.info`スナップショットに依存しており、フィールドの
  欠損・遅延がある場合がある
